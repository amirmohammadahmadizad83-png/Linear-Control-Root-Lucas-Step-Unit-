# Linear-Control-Root-Lucas-Step-Unit-
Linear control system analysis and response evaluation using Python, root locus, and unit-step response methods.

1. Interactive Root Locus Tool

This project develops an interactive Python tool for root locus analysis in linear control systems. It allows users to define open-loop zeros, poles, and gain, then visualizes how closed-loop poles move in the complex plane as gain varies. The tool supports real-time interaction, including draggable poles and zeros, a gain slider, and text inputs for parameter updates. It highlights open-loop poles, zeros, and current closed-loop pole positions, helping users study stability, gain margins, and transient behavior. The implementation uses the control systems library and Matplotlib, making it suitable for both educational and engineering applications.

2. Interactive Step Response Analyzer

This project implements an interactive step response analyzer for linear time-invariant systems. Users can input arbitrary transfer functions or generate standard second-order systems by adjusting damping ratio and natural frequency. The tool computes key performance metrics including overshoot, settling time, and rise time, and displays the step response graphically. It also identifies dominant poles and extracts relevant system parameters. With real-time sliders and input validation, the tool provides an intuitive platform for comparing system responses, understanding transient performance, and analyzing parameter effects in control system design.
